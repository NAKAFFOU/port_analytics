# Service Catalogue — Categories and Finished Products (PSL)

This describes every `CATEGORIE` and `PRODUIT_FINI` value used by the
synthetic `RECETTE_PF`/`ADIRECTE_COUT`/`AINDIRECTE_COUT` export generated by
`src/db/seed_demo.py::generate_synthetic_oracle_views` (there is no data
from a real organisation anywhere in this repository — see
`docs/ARCHITECTURE.md`), in both languages. These descriptions are drawn
from standard port-industry terminology — for a real deployment this would
be a starting point for the business owner to confirm or correct against
their own JDE definitions, not an authoritative source in itself.

Source labels and their English translation are centralised in
`config/mappings/oracle_pbi_views/service_lines.csv`
(`target_category_name`/`target_category_name_en`,
`target_service_name`/`target_service_name_en`); this document explains what
each one *means*, not just its translated label.

| Source (`CATEGORIE`) | FR | EN | Description (FR) | Description (EN) |
|---|---|---|---|---|
| `Marchandises` | Marchandises | Cargo | Recettes et charges liées à la manutention et au traitement du fret transitant par le port. | Revenue and costs related to the handling and processing of cargo/freight moving through the port. |
| `Services Maritimes` | Services Maritimes | Maritime Services | Prestations nautiques directement liées à l'escale des navires (pilotage, remorquage, lamanage). | Nautical services directly tied to a vessel's port call (pilotage, towage, mooring). |

| *(vide / blank)* | Uncategorised | Uncategorised | Lignes sans catégorie renseignée dans la source ; corriger via le mapping `service_lines.csv` plutôt que dans le code. | Rows with no source category recorded; correct via the `service_lines.csv` mapping rather than in code. |

## Notes

- A finished product belongs to exactly one category in the current data
  (verified against the synthetic export); there is no product that appears
  under more than one category.
- `Uncategorised` is a pipeline fallback (`src/ingestion/oracle_views.py`),
  not a value that exists in the source — it only appears if `CATEGORIE` is
  blank for a row that does have a `PRODUIT_FINI`.
- These descriptions do not affect any calculation — they are documentation
  only. Renaming a label is done in `service_lines.csv`, never here.
